## 📖 About the Project

**Shree Ambika Metal** is a responsive, feature-rich web application designed to showcase metal services and streamline customer inquiries. It provides an intuitive interface for clients to explore services, read testimonials, and submit booking requests, all while offering administrators a secure backend to manage operations.

## ✨ Key Features

*   **Service Showcase:** Detailed sections highlighting core offerings and business strengths (`Services.tsx`, `WhyChooseUs.tsx`).
*   **Customer Engagement:** Integrated testimonials and contact sections to build trust and facilitate communication (`Testimonials.tsx`, `ContactSection.tsx`)[cite: 3].
*   **Online Bookings:** A dedicated booking form for clients to easily request services (`BookingForm.tsx`)[cite: 3].
*   **Admin Dashboard:** A secure administrative panel to manage inquiries and platform data (`AdminPanel.tsx`)[cite: 3].
*   **Real-time Database:** Powered by Firebase Firestore for seamless data syncing and secure backend storage (`firestore.rules`, `firebase.ts`)[cite: 3].

## 🛠️ Tech Stack

*   **Frontend:** React with TypeScript (`App.tsx`, `types.ts`)[cite: 3].
*   **Build Tool:** Vite (`vite.config.ts`)[cite: 3].
*   **Styling:** Tailwind CSS (`index.css`)[cite: 3].
*   **Backend / Database:** Firebase & Firestore[cite: 3].
*   **Deployment:** Vercel

### Prerequisites
*   Node.js (v18 or higher)
*   npm or yarn
*   A Firebase project setup
